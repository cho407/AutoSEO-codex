# SEO Image Specifications

Use these defaults only when the user has not supplied brand or platform rules.

| Use case | Suggested ratio | Suggested size | Notes |
|---|---:|---:|---|
| Open Graph | 1.91:1 | 1200 x 630 | Keep essential text away from edges. |
| Article hero | 16:9 | 1600 x 900 | Prefer a clean focal point and meaningful alt text. |
| Square social | 1:1 | 1200 x 1200 | Verify the destination platform before export. |
| Product detail | 1:1 | 1600 x 1600 | Preserve product appearance; do not invent claims. |

## Safety and provenance

- Use only an image tool already available and authorized in the current Codex host.
- Do not install a model, package, MCP server, or connector automatically.
- Ask before spending paid credits or sending confidential brand assets externally.
- Save into a user-approved project directory and never overwrite an existing file
  without confirmation.
- Record the prompt, model/tool name when available, creation date, and any required
  AI-content disclosure metadata alongside the output.
- Verify trademark, likeness, medical, financial, and product-claim risks before use.
