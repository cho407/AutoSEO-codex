# 다음 작업과 제목 전략

갱신: 2026-09-14. 무료·로컬 우선, 기존 글 보존, 글별 발행 승인을 유지한다.

이번 진행: 로컬 진입 감지와 현재 세션의 저장 확인·중단 경계를 구현했고,
작성 스킬에 1,500자·트렌드·카테고리·대표 이미지/도식·영문 UI 로케일을 묶은
로그인 후 한 번 저장하는 흐름을 연결했다. 실계정 초안 ID 발견, 플랫폼별
변환/서식, 실제 발행·예약은 아직 검증 완료가 아니다. 4번 독립형 제목 후보
기능은 검토 후 등록했으며 아직 구현 전이다(블로그 모드의 무주제 트렌드 선택과는 별도).

## 우선순위

1. **P0 — 편집기 진입·초안 보존:** iframe/기본 모드 진입 감지, 현재 세션의 저장 확인, 안전한 재개와 수동 조정 경계. 로컬 검증과 실계정 검증을 따로 기록한다.
2. **P0 — 실제 발행·예약 결과:** 승인된 실제 화면 근거로 플랫폼별 초안/글 ID와 공개·예약 상태 연결을 보완한다. 모호한 결과는 재시도하지 않는다.
3. **P1 — 공통 이미지 개인정보 처리:** 네이버 일반/그룹/교체 사진에도 티스토리와 같은 모자이크·파생 파일 승인 경로를 연결한다.
4. **P1 — 제목 후보와 사실 검토:** 아래 원칙으로 검색형·피드형·균형형 후보를 제안하고 사용자가 선택한다. 작성 흐름 통합에 앞서 구현할 작은 작업이다.
5. **P1 — 통합 작성 흐름:** 가이드와 현재 세션 저장 경계를 연결했다. 최신 근거 수집, 말투/윤문, 제목 선택, 이미지 처리, 실계정 변환·서식의 live 검증과 실행 기록을 보완한다. 오래된 근거는 발행 직전에 재검사한다.
6. **P2 — 글별 성과:** 동일 기간·시장·검색/추천 표면의 소유자 제공 자료를 비교해 수정 후보를 제안한다. 점수 상승을 노출 증가로 간주하지 않는다.

## 네이버 제목 요령 검토

첨부 자료의 호기심·숫자·구어체 활용은 **실험할 편집 원칙**으로 일부 채택한다. 네이버 검색과 홈피드는 같은 표면이 아니다. 네이버는 홈피드를 이용자의 관심사와 활동에 따른 개인화 추천으로 설명한다. 특정 제목 공식이나 수익 화면만으로 추천·수익 효과를 입증할 수 없다. [홈피드 공식 설명](https://www.navercorp.com/media/pressReleasesDetail?seq=2278)

검색용 개별 페이지 제목은 콘텐츠 주제를 명확하게 설명하고 고유해야 한다는 공식 안내가 있다. 제목에 핵심 대상을 무조건 숨기는 방식은 기본값으로 삼지 않는다. 이 안내는 웹 검색 원칙이며 홈피드 추천 알고리즘 명세가 아니다. [콘텐츠 마크업 안내](https://searchadvisor.naver.com/guide/markup-content)

| 요령 | 적용 판단 |
|---|---|
| 질문형·자연스러운 말투 | 본문이 질문에 답하고 선택한 톤과 맞으면 후보로 제안한다. 질문형이라는 이유만으로 가산점을 주지 않는다. |
| 구체적인 숫자 | 실제 목록 수·가격·기간과 일치할 때만 사용한다. 가격·기간에는 적용 조건과 확인일을 연결한다. |
| 궁금증·의외성 | 대상과 독자 효용은 드러내고, 결론 일부를 남기는 후보를 선택적으로 제공한다. |
| 희소성·손실 우려·인기·타인의 반응 | 실제 근거와 유효 기간을 확인할 수 있을 때만 쓴다. 품절·구매 제한·항의·줄서기·후기를 만들어내지 않는다. |
| 강한 감정·개인 경험 | 사용자가 밝힌 경험/감상과 맞는 범위에서만 사용한다. 직접 써봤다는 가짜 경험을 넣지 않는다. |
| 제품명/핵심 정보 숨기기와 공식 반복 | 일반 규칙으로는 제외한다. 검색 의도와 제목–본문 일치를 해치는 템플릿을 복제하지 않는다. |

네이버는 제목·설명과 실제 내용이 일치하지 않는 낚시성 콘텐츠, 무의미한 키워드 반복과 대량 유사 콘텐츠를 스팸 사례로 설명한다. 이는 모든 호기심형 제목이 제재된다는 뜻은 아니다. [스팸 사례 안내](https://searchadvisor.naver.com/guide/content-abusing)

### 구현할 작업: 제목 후보 + 근거 연결

- 기본은 **균형형**. 검색형은 대상/의도를 명확히, 피드형은 대상/효용을 유지하면서 호기심을 더한다. 서로 다른 제목을 검색봇과 독자에게 숨겨 보여주지 않는다.
- 하나의 본문에서 3개 안팎의 후보와 선택 이유, 확인할 주장만 제안한다. 게시된 글의 제목을 자동 반복 변경하거나 대량 게시로 실험하지 않는다.
- 제목의 숫자·가격·인기·희소성·경험 주장을 본문과 최신 출처/사용자 확인에 연결한다. 기계 검사는 숫자 불일치 등 명확한 진단만 맡고 의미·사실성은 근거가 없으면 미측정으로 둔다.
- 제목 품질/실험 가설을 SEO·NEO 준비도 점수나 예상 CTR, 순위·수익 보장값과 섞지 않는다. 피드/검색의 실제 관측 결과는 따로 비교한다.
- 고정 글자 수, 감탄사 개수, 키워드 밀도를 보편적인 합격 규칙으로 넣지 않는다. 화면별 잘림과 가독성은 미리보기로 확인한다.

완료 기준: 본문과 다른 목록 수·근거 없는 품절/인기·가짜 사용 후기가 승인 없이 통과하지 않는다. 정보형 질문, 검증된 기간/가격, 개인 경험 없음 사례를 구별한다. 원본 본문과 사실은 후보 생성/선택 중 바뀌지 않으며, 사용자 말투가 보존된다. 효과 확인에는 표면·기간·노출수·클릭수와 한계를 기록하고 전후 차이를 인과 효과로 단정하지 않는다.

이 제목 기능은 **작업 목록에 등록된 상태**이며 아직 자동 후보 생성기나 점수 기능으로 구현하지 않았다. 원본 이미지·개인 계정 화면·수익 수치는 저장소에 포함하지 않는다.
